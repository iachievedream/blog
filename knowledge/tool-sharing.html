This page cannot be clipped. Only http and https URLs are supported.

因為它只能在使用在一般模式
而無法在閱讀模式下使用

google 關鍵字

『obsidian web clipper chrome 手機』
google 出現以下資訊
手機版 Chrome 無法直接安裝桌面端的 Obsidian Web Clipper
但你可以透過 Android 系統的 Firefox
或 iOS 系統的 Safari 達成相同的網頁剪輯需求

手機替代方案與設定方式

Android 手機

下載並使用 Firefox 行動版，前往擴充功能商店安裝 Obsidian Web Clipper 即可直接使用

iPhone / iOS 手機

使用 Safari 瀏覽器，透過分享選單啟用並設定該擴充功能來剪藏網頁

備用替代方法

若使用手機 Chrome，可直接利用瀏覽器的「分享」功能，將網頁連結傳送到手機內的 Obsidian App 建立新筆記
